⚠️ 整条链路的核心难点
🗣️
1. 客户需求结构化
客户说的话是模糊的——"我想要更多转化""内容感觉不对"。AI Bot 能收信息，但把非结构化反馈转成"调整内容方向 X、出价策略 Y"，中间需要一套映射逻辑，目前没有现成方案，要自己摸。
✅ 解法：用 AI Bot 引导客户说出 KPI、预算、竞品等关键信息，AI 自动解析成结构化字段，并给出相应的投放策略和内容生产建议；同时 AI Bot 实时回应客户问题，人工在旁辅助处理复杂情况。
📋
1.5 策略输入永远残缺
客户给的信息永远不完整——KPI 没有、竞品说不清楚、行业背景一句话带过。以为能自动生成策略报告，实际上70%的时间在补信息，自动化前提不成立。
✅ 解法：用 AI Bot 引导客户说出 KPI、预算、竞品等关键信息，AI 自动解析成结构化字段，并给出相应的投放策略和内容生产建议。
💬
2. 客户沟通与情绪承接
直接对接客户不只是传递信息，还要建立信任、管理预期和处理反馈。这部分保留人工负责。
✅ 解法：沉淀通用沟通模板和问题分类，由业务人员处理复杂情况。
🧠
3. 公司记忆 / 知识库建设？
历史客户案例、优质内容模板、各行业投放经验——这些要被 AI 在对话中正确调用，需要先做结构化存储（RAG / 知识库），不是一个 Bot 就能解决的，是持续维护的基建，工程量最大。
✅ 解法：先做最小版本——把过往跑出来的好内容、好方向存成文档，每次生成前手动喂给 AI 作为上下文，积累到一定量再考虑向量数据库。
⚡
3.5 账户搭建策略谁拍板
AI Bot 识别出"客户要提升转化率"之后，转成具体账户搭建策略没有标准答案，不同优化师做法不一样，AI 给的建议优化师未必认可——这个断层目前没有解法。
✅ 解法：AI 只出选项不拍板，给优化师 2-3 套方案 + 各自适用场景，人来决策，AI 帮完善细节。把 AI 定位成"出方案的"，人定位成"决策的"。
🧭
4. 客户沟通与投放账户不熟悉
客户沟通与账户搭建有明确的业务判断边界，需要结合实际场景确认标准流程。
✅ 解法：基于通用沟通模板和账户操作规范，先验证流程再扩大应用。
🔗
5. 各节点数据格式不通
客户沟通产出文字，内容产出图文，投放产出 CSV——三块格式完全不同。要让整条链路自动流转，需要在每个节点之间做数据转换和标准化，工程量不小。
✅ 解法：定义一个中间层数据格式，所有节点输出统一转成标准结构，之后每增加新节点只需对接这个中间格式。
📥
5.5 数据源还是手动触发
数据处理 SOP 已跑通，但每次还是要人工下载 CSV。小红书后台能否定时导出、能否 API 对接，还没打通——真正的自动化需要数据源自动推进来。
✅ 解法：短期接受手动，通过调研发现小红书 API 可实现自动化则可以接入自动分析。
📊
5.8 数据口径对不上
客户那边可能用另一套系统看数据，两边数字对不上时，解释成本比生成报告的成本高得多。报告生成不难，难在口径对齐。
✅ 解法：第一次对接时和客户对齐口径，写进合作说明；每份报告开头加"口径说明"，让客户先看定义再看数字。
🚧
6. 投放账户操作未自动化
内容生成已跑通，但"内容 → 上传投放平台 → 绑定计划 → 调整出价"这段还是手动的。小红书 API 开放程度有限，这块能自动化到什么程度需要先调研。
✅ 解法：先调研小红书投放平台 API 开放范围，能接的部分先接，不能接的暂时保持手动，优先把其他环节跑通。
🎯 操作优先级 先从客户切入还是先从账户切入？
P0
1. 需求收集 AI Bot — 通过过往聊天记录查看对话风格和客户痛点
2. 数据口径对齐文档 — 理清客户项目的数据口径
P1 · 有了账户再做
3. 账户搭建策略模板 — AI 出 2-3 套方案供优化师选，需要先有账户验证
4. 中间层数据格式 — 统一各节点输出结构，需要先把几个节点都跑起来才能定
P2 · 长期
5. 小红书 API 调研 — 看能否接入自动数据推送，替代手动下载 CSV
6. 数据看板搭建 — 客户端 + 内部端，等数据流稳定后再做
